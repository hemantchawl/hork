- `restaurants.json` — derived from the [Overture Maps Foundation](https://overturemaps.org) places theme
  (release 2026-09-23.1). © Overture Maps Foundation and contributors. Places data is licensed under
  [CDLA Permissive 2.0](https://cdla.dev/permissive-2-0/); records sourced from Foursquare Open Source Places
  are licensed under [Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0). Each record keeps its
  `sources` so attribution can be traced per place.
- `menu_items.json` — menus published on each restaurant's own website (see `source_url` on every item),
  structured for this private prototype. Menus belong to the restaurants; review terms before any public launch.
- `users.json`, `logs.json`, `follows.json` — created by testers using the app.
